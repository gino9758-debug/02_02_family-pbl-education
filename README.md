# 家庭PBL教育实践

家庭 PBL 项目设计与家庭教育实践的方法论 Skill（Family PBL Education）

## 项目解决什么问题

家长想带孩子做项目制学习，但缺设计方法、缺选题、缺评估标准；家庭教育中电子用品、游戏、多巴胺管理等问题缺少体系化框架。本技能把 PBL 设计、家庭教育第一性原理、家庭会议机制沉淀成可直接套用的方法论。

## 主要功能

| 能力 | 说明 |
|------|------|
| PBL 设计方法论 | 项目六要素、PBL 标准模板、50+ 选题库、评估标准 |
| 家庭教育实践体系 | 家庭教育第一性原理、自驱型家庭系统、时间管理、电子用品规范、家庭会议议题生成器 |
| FLEE 模型 | 耗散结构家庭教育四维模型 |
| 儿童哲学 | 马修·李普曼方法 + 聊天盲盒式话题搭建 |
| 专项管理 | 游戏管理与多巴胺调控、家庭美育氛围营造 |
| 适龄校准 | 输出前必做的适龄适配检查 |

## 安装方法

将本目录放入你的 Agent 技能目录（如 `~/.codex/skills/`、`~/.claude/skills/`），重启会话后生效。

### 要求
- 无第三方依赖；输入孩子年龄/主题/目标即可使用

## 使用方法

触发场景：设计 PBL 项目、家庭会议、孩子教育、游戏管理、亲子对话、儿童哲学、SDGs 教育、家庭美育、自驱型家庭、FLEE 系统。

## 输入输出示例

**输入：** 设计一个 8 岁孩子的社区探索 PBL 项目
**输出：** 按 PBL 六要素 + 标准模板输出的项目方案（含选题、评估标准）

**输入：** 生成本周家庭会议议题，孩子 6 岁和 10 岁
**输出：** 家庭会议议题清单（含电子用品规范议题）
